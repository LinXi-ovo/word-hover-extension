# Word Hover 释义助手

一个 Chrome / Edge 浏览器扩展：打开英文网页后点击按钮，AI 自动挑出值得学习的词组并标黄；悬停任意英文单词或词组，即可在鼠标旁看到语境中的中文释义。

> 状态：早期版本（0.1.0），尚未发布到应用商店，需以开发者模式手动加载。

## 功能

- **一键分析本页**：点击扩展图标后点“分析本页”，AI 挑选词组并在页面中标黄。
- **悬停查词**：悬停任意英文单词，调用模型根据所在句子给出简短中文释义；同一单词之后从缓存读取。
- **悬停词组**：分析得到的词组悬停时，显示 AI 给出的释义，并高亮整个词组。
- **自定义接口**：支持任何 OpenAI 兼容的 Chat Completions 接口（DeepSeek 官方、代理服务等）。
- **本地保存设置**：API Key、接口地址、模型名只保存在浏览器本地。

## 安装

1. 克隆或下载本仓库。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库所在的文件夹。

修改代码后，需要在扩展页面点击“重新加载”。修改 `manifest.json` 中的权限后尤其需要重新加载。

## 配置

1. 点击浏览器工具栏中的扩展图标。
2. 填写以下三项：
   - **API Key**：你的服务商密钥。
   - **API 地址**：填到 `/v1` 即可，例如 `https://api.deepseek.com/v1` 或 `https://amr-link.open-design.ai/v1`。扩展会自动补上 `/chat/completions`；填完整地址也可以。
   - **模型名**：例如 `deepseek-chat` 或 `deepseek-v4.1-flash`。
3. 点击“保存设置”。

## 使用

1. 打开一个英文网页。
2. 点击扩展图标，再点“分析本页”。
3. 页面右下角会显示进度。完成后，标黄的词组即为 AI 挑选的学习词组。
4. 悬停任意英文单词或标黄词组，即可在鼠标旁看到中文释义。

## 工作原理

```
页面脚本 (content.js)  --消息-->  后台 (background.js)  --HTTPS-->  你配置的模型接口
      ↑ 显示释义、标注词组              ↑ 唯一持有 API Key 并发起请求
```

- **`manifest.json`**：声明权限，只使用 `storage`、`activeTab`、`scripting`，并允许访问 HTTPS 接口。
- **`popup.html` / `popup.js`**：设置面板，保存配置，并把分析任务注入当前页面。
- **`background.js`**：唯一与模型接口通信的部分。页面脚本拿不到 API Key。
- **`content.js` / `content.css`**：注入页面，负责分段提取文本、标注词组、显示悬停提示。

## 隐私与费用

- **API Key 只保存在本机**，存放在 `chrome.storage.local`，不会上传到仓库或任何第三方。
- **“分析本页”会把页面文字发送到你配置的接口**。请不要在包含敏感信息的页面上使用。
- **每次分析最多处理 8 段文字**（约 3 万字符），以控制费用。
- **悬停查词会为每个新单词调用一次接口**。同一页面内的结果会缓存，同一单词之后不重复请求。

## 已知限制

- 跨元素的词组（中间夹有链接、加粗等标签）暂不标注，但单词悬停仍可用。
- 多义词的释义取决于所在句子，偶尔可能不准确。
- 长文需要多次点击“分析本页”，每次只处理前 8 段。
- 目前只在 Chromium 内核浏览器中开发测试，Firefox 不支持。
- 依赖模型服务的可用性和速度，接口返回慢时悬停提示会显示“查询中…”。

## 常见问题

**显示 `API 404`**：通常是 API 地址填错。确认地址以 `/v1` 结尾（或完整的 `/chat/completions`），不要多写路径。

**显示“未设置 API Key”**：打开扩展弹窗，填写并保存密钥。

**改了配置没有生效**：保存设置后，需要刷新目标网页再试。

**悬停没有反应**：确认页面是普通网页（`chrome://` 页面和部分商店页面不允许注入脚本），并且已点过“分析本页”或悬停的是英文单词。

## 目录结构

```
word-hover-extension/
├── manifest.json     扩展配置与权限
├── popup.html        设置面板界面
├── popup.js          设置保存与触发分析
├── background.js     与模型接口通信（持有 API Key）
├── content.js        页面注入：标注词组、悬停显示
├── content.css       注入样式
├── README.md
└── .gitignore
```
